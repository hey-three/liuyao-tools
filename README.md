# li — 个人小工具集

零依赖、双击即用的单文件 HTML 小工具集合。

## 工具清单

| 工具 | 文件 | 用途 | 怎么用 |
|---|---|---|---|
| 十二地支关系查询 | `tools/地支关系查询.html` | 六爻解卦辅助：点击任一地支，查看它与其它地支的六冲 / 六合 / 三合 / 相刑 / 相破 / 暗合关系 | 双击文件 → 浏览器打开 → 点圆盘上的地支 |

## 快速上手（傻瓜步骤）

1. 打开文件夹 `tools`；
2. 双击 `地支关系查询.html`（自动用浏览器打开，**无需联网、无需安装任何东西**）；
3. 点击圆盘上任意地支（如「子」）→ 右侧立即列出它的全部关系；
4. 点击右侧结果里的地支，可以继续切换查询；
5. 再点一次已选中的地支，回到「总表」模式。
